# 设计说明

本 Skill 负责把已有意向转成购买，再把购买转成持续的客户价值。入口根据当前问题加载需求发现、商机交付、激活转化、留存扩展或执行交接方法，不要求一项任务穿过所有阶段。

每份方法都围绕会改变下一步行动的判断：需求是否真实、购买角色是否参与、试点能否验证价值、承诺能否交付、首次价值在哪里中断，以及续费风险是否可解决。客户行动定义阶段，销售活动只作为活动记录。收入与留存使用可核对的范围和分母，固定行业数字不构成通用过关线。

安装单元只含入口、五份按需方法、一个交接模板、客户端元数据与许可。没有运行脚本、专用服务或其他 Skill 依赖。已有工具可以承担授权的 CRM 更新与客户操作；没有工具时产出可继续执行的材料，并如实区分状态。

这个边界支持五个独立仓库协作：本部分不选择全新市场，不制作通用营销内容，不开发陌生渠道，也不将前后变化宣称为实验因果。遇到这些任务时给出必要输入和反馈，相关部分是否被调用取决于用户任务与可用环境。

验证分成结构检查与业务执行。结构检查检查文件能否安装和找到；业务任务检查实际判断、材料和状态是否正确。单次成功不能证明稳定性或业务增长，后续改动应针对实际发现的问题，不为测试数量持续扩充方法。
