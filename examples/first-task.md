# 销售转化与客户增长：一次完整任务

以下为合成材料的工作示例，输入与输出节选经过编辑整理，不是真实客户结果。

## 输入

```text
使用 $global-sales-retention。
产品背景：英语 Shopify 退货分析工具，支持 CSV 手动导入、原因与 SKU 汇总、手动 PDF 导出，99 美元/月，本月不自动续费。

这个产品本周收到两类意向：小品牌运营主管愿意做 CSV 引导试点，老板还没确认预算；一家代理商愿付 500 美元/月，但前提是明天上线跨店权限和自动同步，目前没有这些功能。创始人本周有 3 小时支持，可以完成两个 60 分钟引导。请决定先推进谁，写一封给小品牌运营主管的英语跟进邮件，安排试点从首次导入到购买的具体动作和成功/停止条件。另做现有客户复盘：月初同一付费队列 MRR 为 1,000 美元，月底其中流失 200、降档 100、增购 150，新客户另带来 300。算这个队列 GRR 和 NRR，判断收入变化能否证明留存健康。客户签约、付款、首次完成任务要分清，不执行任何外部动作。
```

## 输出节选

先推进能用现有 CSV 流程的小品牌，确认付款人和试点范围；暂缓明天必须交付不存在功能的代理商商机。

原客户队列 GRR 为 70%、NRR 为 85%；加上新客后总 MRR 上涨 15%，仍不能证明老客户留存健康。

## 接下来怎么用

检查建议中的条件与你的实际产品是否一致，再补真实链接、责任人和授权。一次性任务直接使用正文即可；持续项目保留输入、来源、产物版本及下一步。方案和草稿不表示已执行，演示结果不证明真实业务收益。
